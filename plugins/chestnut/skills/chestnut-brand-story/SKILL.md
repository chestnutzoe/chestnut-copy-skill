# 个人品牌故事

这是可独立使用的公开版，不依赖作者的私人资料、其他 Skill 或付费课程。先读用户指定的经历、旧文章、日记、主页或语音转写；读取不了的链接请用户贴正文，不假装已经读过。无需先填完定位问卷。

## 对话

1. 区分真实事件、当时感受、现在理解和仍不确定的解释。AI 旧稿不是人生事实；不替他人读心，记不清的对白用转述。
2. 有材料就先提出一条暂定主线：过去处境、经历的选择或转折、现在在做什么。没有材料，先问“你为什么想重新介绍自己？”一次只问一个真正缺失的问题。
3. 寻找影响方向的具体片段，不把履历逐年罗列。变化可以渐进，可以尚未完成，不要求创伤、成功或顿悟。用户说不想分享的部分不再追问。
4. 根据真实经历，辨认哪些人可能产生共鸣或得到帮助。没有证据时先作候选，不强行把故事转成销售，不用商业选题评分淘汰用户的自我表达。
5. 用几句话复述主线，让用户纠偏。核心意义未确认时不擅自定稿；用户已经明确想说什么，就直接继续。

## 成稿

按用户所需的文章或口播组织；未说明时先问形式。材料充分后输出完整初稿，不停在一张故事卡。

- 让读者知道当时在意什么、做了什么、遇到什么、之后有什么不同。
- 关键处保留具体行动、真实感受和必要细节；背景可以概括，不编造感官信息。
- 区分当时不知道的事与今天的回望。用因果检查顺序，但不制造因果。
- 保留使用者原话和提供的声音样本，不模仿 Skill 作者的语气。没有样本时用清楚、自然的语言。
- 结尾落在现在的选择、仍在探索的问题或希望分享的东西，不额外加鸡汤或购买引导。

交付一篇初稿和必要的待核实事实；无事实缺口就不附一堆检查说明。修改以用户最新稿为准。发布与更新账号由用户决定，不自动执行。

## 编辑检查

先检查主线和顺序，再看句子。只提最影响理解的一两项修改：哪处缺现场、哪段重复、哪条漂亮旁支转移了重心。不能为了简短删掉关键事实，也不能用“我终于明白”替代完整过程。

方法启发：Matthew Dicks 的《Storyworthy》（真实变化、关键瞬间、行动与后果）；这里是非虚构适配，不是官方工具，不附带原书，也不要求用户购买原书。
